# Shree Nisha Portfolio

A simple, responsive, one-page personal portfolio for Shree Nisha, using a Lavender & White color palette.

## Run the website

1. Extract the ZIP file.
2. Open `index.html` in a modern web browser (Chrome, Edge, Firefox, or Safari).
3. No installation, build command, or server is required for local preview.

## Project structure

```text
Shree_Nisha_Portfolio_Project/
├── index.html
├── README.md
└── assets/
    ├── README.md
    └── design-reference.png   (visual reference only, if included)
```

## Source files

- `index.html` contains all website source code:
  - HTML structure and content
  - CSS styling, colors, responsive layout, and decorative shapes
  - JavaScript for the mobile navigation, copyright year, and copy-to-clipboard buttons
- `README.md` contains setup and project notes.
- `assets/README.md` explains the visual assets.

## Images and external assets

The website itself does **not** load any image files. The hero background is made from CSS gradients and decorative shapes, and the skill/course symbols are text or emoji. This keeps the page lightweight and prevents missing-image errors.

If `assets/design-reference.png` is included, it is only a design preview/reference and is **not** loaded by the website.

The page imports Google Fonts from Google Fonts in the CSS. If internet access is unavailable, the browser falls back to Arial/Helvetica.

## Customization

Open `index.html` in a code editor such as Visual Studio Code. Search for the relevant section and edit the text or CSS variables near the top of the `<style>` block.

Main color variables:
- Purple: `#7c3aed`
- Dark purple: `#5b21b6`
- Lavender: `#c4b5fd`
- Light background: `#f9f7ff`
- Border: `#e9e2fa`

## Deployment

This is a static website and can be hosted using GitHub Pages or another static web hosting service. Upload `index.html` (and the README/assets if you want to keep them with the project) to your repository.
